# ADR-0005-m: Cover мигрированных статей — первая редакционная картинка

- Статус: Предложено (черновик наставника по решению владельца 2026-08-31,
  вариант 3Б; пункт с ⚠ — на подтверждение владельцем при коммите)
- Дата: 2026-08-31
- Серия: m-ADR миграции; дополняет 0002-m (ADR-0010): тот снял с конвейера
  измерение картинок ТЕЛА (`Figure` читает файл при сборке) и оставил
  открытым источник размеров для `cover` — здесь он назначается.

## Контекст

`cover` в схеме арки A опционален и имеет форму `{ src, alt, width,
height }` — все четыре поля обязательны, когда обложка есть: карточки
списков рендерят её вне `Figure`, и `next/image` требует размеры заранее.
`var/s7-ready.jsonl` несёт у каждой статьи `images[{src, path, kind}]`
в порядке документа, `kind ∈ editorial | product`. Приёмка S6
гарантирует: файл каждой редакционной картинки выпущенной статьи лежит
в `public/<path>` и закоммичен. Подпись каждой редакционной картинки
разрешена ещё в S5 (`alt` из тела либо `config/alt-texts.ts`, иначе
статья ушла бы в карантин), но в запись `images` подпись сейчас НЕ
пишется — только в текст `mdx`.

## Решение

1. **Cover — первая запись `images` с `kind: 'editorial'`** в порядке
   документа; выбор детерминирован структурой статьи. Статья без
   редакционных картинок мигрирует без `cover` — поле опционально,
   карточка обязана уметь «без обложки» (такие статьи в корпусе есть).
   Товарные картинки на роль обложки не годятся: их файлов на новом
   сайте нет (ADR-0010), и карточка глядела бы на чужой домен со сроком
   годности.

2. **`src` обложки = `path` записи** — корневой адрес, одно
   преобразование в одном доме (S5); S8 адрес не трогает.

3. **Размеры меряет S8**: `image-size` (`imageSizeFromFile`) по файлу
   `public/<path>`. Отказы — **карантин** с самодостаточной причиной:
   файла нет («рассинхрон с S6: перепрогнать copy_img или вернуть файл
   `public/<path>`»), файл не читается или даёт нулевую ширину/высоту
   («битый файл — заменить в зеркале и перепрогнать copy_img»). Смерть
   не выбрана: беда одной статьи не должна останавливать остальные
   пятнадцать, а инвариант «S6 скопировала» доказан её приёмкой, но не
   гарантирован навечно — файл могли удалить руками.

4. ⚠ **`alt` обложки приезжает из S5: запись `images` расширяется полем
   `alt`** — той самой разрешённой подписью, что ушла в `![alt](path)`.
   Правка `convert.ts` точечная (в `renderImage` подпись уже вычислена —
   добавить её в `ctx.images.push`), затем перепрогон
   `convert → copy_img → rewrite_links`: S6 пронесёт поле дословными
   строками, S7 — спредом записи, правок их кода не нужно. Цена —
   смена md5 у артефактов S5–S7 и повторная быстрая приёмка
   (идемпотентность, сверка «mdx не изменился»). Подтверждение
   владельца обязательно: правится закрытая стадия.
   Отвергнутая альтернатива: S8 вычитывает `alt` повторным разбором
   `mdx` — второй парсер и второй дом подписи ради одного поля; тот же
   запах, из-за которого S6 в своё время получил готовый `path` от S5.

5. **Идемпотентность сохраняется**: размеры — чистая функция файлов, а
   файлы лежат под манифестом S6 в git; повторный прогон S8 даёт те же
   байты.

6. **Слепота выбора — принятая цена.** «Первая редакционная» может
   оказаться виньеткой или мелким сканом; правка — редакционная, по
   готовому MDX. В отчёт S11 добавляется класс «cover назначен
   автоматически» со списком статей — это и есть рабочий список для
   редакционного прохода.

## Рассмотренные альтернативы

- **3А: мигрировать без cover.** Ноль кода и отказов, идеальная
  обратимость, но карточки статей с живыми иллюстрациями остаются
  пустыми, а редакционное назначение потом — та же работа вручную по
  всем статьям. Отвергнуто владельцем.
- **3В: ручная карта id → cover для подвыборки.** Редакционное качество,
  но ручной труд и лишний вход конвейера; на 1338 не масштабируется,
  а то же самое достижимо правкой фронтматтера после S9. Отвергнуто.
- **3Г: дефолтная обложка (общая или по рубрике).** Требует
  несуществующего дизайн-ассета, карточки монотонны. Отвергнуто.
- **Эвристики «лучшей» картинки (размер, положение).** Недетерминизм
  и сложность не окупаются; редакционный проход по отчёту дешевле.
  Отвергнуто.

## Последствия

- `convert.ts`: поле `alt` в записи `images` (п. 4) + перепрогон S5–S7
  с приёмкой.
- S8: зависимость `image-size`; ветки карантина по файлу.
- Отчёт S11: класс «cover назначен автоматически».
- DEBT-B: строка «cover…» (2026-08-27) закрывается ссылкой на этот ADR.
- Декомпозиция: ревизия №7 раздела S8.
