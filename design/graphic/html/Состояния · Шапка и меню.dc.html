A · Ховер коричневой навигации — решено: ни A1, ни A2
шаг 1: цвет не меняется вовсе, отклик — линия

Навигация набрана --color-heading; правила ховера для этого цвета в системе нет. Наведите курсор на оба ряда.

A1 · ховер в бирюзу
{{ n }}
Что сообщает: «это ссылка, как все ссылки сайта». Единое правило интерактива, прецедент — ховер нейтрального элемента в пагинации.
color → --color-link-hover
A2 · сгущение тона
{{ n }}
Что сообщает: «элемент откликается», не меняя смысла цвета. Шапка остаётся монохромной, бирюза продолжает значить «действие/цена».
color → --color-brown-900

Режим высокой контрастности (forced-colors)

В Windows High Contrast box-shadow не отрисовывается — фокус исчезает полностью. Единственный надёжный механизм — outline: система сама перекрашивает его в Highlight. Решение: в обычном режиме outline прозрачный (визуально не виден, место не занимает — outline-offset компенсирует), в forced-colors он проявляется.

Обычный режим
Вход
Эмуляция forced-colors
Вход
Заливка и текст заменены системными; кольцо-box-shadow исчезло, виден только outline цвета Highlight.
:focus-visible {
  box-shadow: var(--focus-ring);
  outline: 2px solid transparent;   /* маячок для forced-colors */
  outline-offset: 2px;
}
@media (forced-colors: active) {
  :focus-visible { outline-color: Highlight; }
}

Часть 3 · тач и зоны нажатия

768 и 320 · минимум 44×44
Три режима панели «Журнал» (ADR-0004, ам. 2026-08-09): < 1024 — полноэкранное меню с аккордеоном · 1024–1599 — оверлей по бургеру · ≥ 1600 (--breakpoint-dock) — панель-колонка: бургер скрыт, крестика нет, интерактива не существует; центрируется ансамбль --assembly-max 1650 (панель --panel-w 330 + контент 1320), сверх — только поля. Состояния этого листа относятся к пунктам панели во всех трёх режимах.
Дровер 320 · пункты меню
{{ d }}
Пунктирная рамка — кликабельная зона: высота 48 (текст ~20) на всю ширину панели. Зона шире видимого текста — попадание не требует точности.
min-height 48px · padding-block --space-3 · без внешних отступов между целями (разделитель — граница)
Шапка 768 / 320 · иконки-кнопки
Видимая иконка 20×15, зона 44×44 — центрируется вокруг глифа. Между соседними целями — минимум --space-2 (8px), чтобы не задеть соседнюю.
Где зона больше видимой границы: все иконки-кнопки (глиф ≈20px, цель 44), пункты дровера (текст ~20px, строка 48), строки списка статей (текст 15px, строка 44+), логотип-ссылка на 320 (высота картинки 62 — цель по картинке, уже ≥44).
