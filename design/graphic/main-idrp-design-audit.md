## 2. Типы страниц (8 шаблонов)

1. **Главная-портал.** Десктоп: 3 колонки (левый сайдбар: рубрики журнала,
   виджет именин, подписка, отзывы; центр: крупные карточки материалов с
   лейблами рубрик, ряд товаров "Последние рекомендации", сетка "Читальный
   зал" 2x2, карточки "События"; правый сайдбар: цитата, баннер,
   товары "Библиотека", лента событий). Мобайл: одна колонка, тот же состав
   в измененном порядке.
2. **Статья (базовый контентный шаблон, он же житие).** Полноширинное фото,
   лейбл рубрики, заголовок с датами памяти (новый/старый стиль), автор-блок
   (круглый аватар + имя + роль; авторов может быть несколько по ходу
   текста), текст с pull-quote (орнаментальные кавычки), фото с подписью,
   видео-embed, соцшаринг (FB/VK/Twitter), ряд "Другие материалы по теме"
   (7 мини-карточек), ряд "События", правый сайдбар как на главной.
   В мобильной версии в тело статьи встраивается товарный блок "Библиотека"
   (2 спроектированных варианта: вертикальная карточка с "Показать больше
   товаров" и горизонтальная карусель).
3. **Именины: хаб.** Формы "Узнайте день ваших именин" (имя + дата рождения)
   и "Как назвать ребенка" (интервал дат), "Именины сегодня" (имена с
   описаниями), "Ближайшие именины" (даты -> поток имен-ссылок), "Случайное
   имя". Левый сайдбар куста: табы мужские/женские, алфавитная сетка,
   "по месяцам" со счетчиками, календарь-виджет. На мобиле сайдбар
   сворачивается в горизонтальное подменю "ПО АЛФАВИТУ | ПО МЕСЯЦУ | ПО ДАТЕ".
4. **Именины: буква.** Многоколоночный (4) список имен на букву + блоки хаба.
5. **Именины: месяц.** "Именины на январь": дата -> имена, + блоки хаба.
6. **Именины: имя.** Портрет, "ближе всего по дате вам подходят" (святые
   покровители со ссылками на даты), происхождение/значение/характер,
   атрибуты (талисман, цвет, камень, знак зодиака), ссылка на полное
   описание.
7. **Меню-оверлей.** Полноэкранное, два состояния: свернутое (6 пунктов нав
   + О нас/Контакты/Вход) и раскрытый аккордеон "Журнал" со списком рубрик
   и статей с анонсами. На десктопной статье то же меню - выезжающая левая
   панель (бургер слева от контента).
8. **Поиск-оверлей.** Строка поиска поверх страницы (макет только 320).

## 3. Сквозной chrome

- **Шапка.** Мобайл: бирюзовая плашка с телефоном -> строка дата/бургер/лупа
  -> крупный логотип (герб + "РУССКIЙ ПАЛОМНИКЪ" + "ИЗДАТЕЛЬСКIЙ ДОМЪ").
  Десктоп: дата слева, "О нас | Контакты | Вход/Регистрация" справа, логотип
  по центру, под ним навбар капсом с letter-spacing: ЖУРНАЛ, СОБЫТИЯ,
  МАГАЗИН КНИГИ (терракотой - внешний раздел), ИМЕНИНЫ, ПАЛОМНИЧЕСТВО,
  ЖИТИЯ СВЯТЫХ, справа иконка поиска.
- **Футер.** Текст о магазине, "Нашли ошибку? Выделите и нажмите Ctrl+Enter",
  копирайт издательства, телефон 8-800.
- **Правый сайдбар** (главная и статья): цитата дня с атрибуцией книги,
  рекламный баннер, товарный блок (Библиотека/Иконы), лента событий.

## 4. Инвентарь компонентов (вход для дизайн-системы)

Токены:
- Палитра: бирюза #65C6CD (действия: кнопки, активные ссылки), терракота
  #DCA28C (лейблы рубрик, цитаты, акценты, вторичная кнопка "Отправить"),
  темно-коричневый #482C17 (заголовки, нав), серые #939598 / #EBEBEB,
  светлый фон, белые карточки с тонкой рамкой.
- Типографика: PT Sans (по верстке des-2016); капс с разрядкой для нав и
  лейблов; крупные центрированные заголовки статьи терракотой;
  дореволюционная орфография как элемент бренда.
- Иконография: тонкие линейные иконки (лупа, календарь, видео, комментарии,
  корзина), орнаментальные кавычки-скобы у цитат.

Компоненты (по убыванию частоты):
- Карточка материала: крупная (фото, лейбл, заголовок, анонс), с оверлеем
  текста на фото, мини-карточка "по теме" (7 в ряд), карточка читального
  зала (2x2).
- Товарная карточка: вертикальная (обложка, автор, название, видео-отзыв +
  N отзывов, цена, "В корзину"), строка в сайдбаре, карусель 320.
- Цитата-блок (сайдбар) и pull-quote (в тексте).
- Автор-блок (аватар, имя, роль).
- Формы: текст-инпут с плейсхолдером, дата-инпут с иконкой, primary-кнопка
  бирюзовая, secondary терракотовая, e-mail подписка.
- Календарь-виджет; алфавитная сетка; "дата -> поток имен-ссылок";
  лента событий (дата + текст); соцкнопки; лейбл рубрики; разделители.
- Меню-оверлей/панель с аккордеоном; поиск-оверлей.

## 5. Пробелы дизайна (закрыть до/в Claude Design)

1. **Лента рубрики журнала** - макета нет ни в одной ревизии (в верстке
   des-2016 есть `rubrika.html`, сделанный по мотивам). Для SSG-журнала это
   ключевой шаблон.
2. **Пагинация** - не спроектирована нигде (ленты, рубрики, месяцы).
3. **Страница результатов поиска** - есть только оверлей ввода.
4. **404/ошибки** - в макетах нет (в верстке есть заглушка).
5. Промежуточный брейкпоинт (1024-1280) не спроектирован.
6. Состояния: hover/focus/ошибки форм/пустые состояния - нет.
7. Хаб "Читальный зал / Библиотека" как раздел - нет (только блоки).
8. "Полное описание имени" (ссылка со страницы имени) - нет макета.
9. Архив старого журнала (39 статей, рубрики патериков) - макетов нет.
10. Сетка статьи снята замером 2026-08-01 (14 колонок/межколонник 18,
    спаны — `design/article-1600-measurements.md`). Осталось: сверить
    главную 1600 (шаг карточек, сайдбар) при вёрстке главной (A13).

## 6. Следствия для новой архитектуры

- Товарные блоки вшиты во все шаблоны (сайдбар, врезки в статье, ряды на
  главной). Для журнальной вертикали (мигрирует первой, магазин позже на
  Medusa) нужен режим "журнал без живого магазина": статические/отложенные
  товарные блоки или их временное скрытие - решить до верстки шаблонов.
- Именинный куст в дизайне - самостоятельный раздел с собственным сайдбаром
  и 4 шаблонами; его реализация отложена ("придумать потом"), но
  дизайн-система должна заложить его компоненты сразу.
- Динамические элементы шаблонов: дата в шапке, "именины сегодня", календарь,
  случайное имя, лента событий - кандидаты на динамические края/ISR, не
  должны ломать статический путь чтения статьи.
- "Ctrl+Enter" (репорт опечаток), вход/регистрация - магазинные сквозняки,
  решить их судьбу в журнальной вертикали.
