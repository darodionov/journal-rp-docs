# Проверки по дампу legacy-БД (для ADR grid-композиции / слагов-URL и конвейера миграции)

Дата: 2026-07-08. Дамп: `/Users/dr/Code/ru.idrp/idrp.ru/DB/2018-11-17_02-10_db_idrp.sql`
(16 ГБ, mysqldump 10.13 / MySQL 5.6.34, снят 2018-11-17). Рядом: `legacy-map.md`,
`legacy-rubrics.md`.

## Метод

- docker/mysql в среде недоступны, поэтому: собственный потоковый токенайзер
  INSERT-значений на Python -> загрузка нужных таблиц в SQLite -> запросы SQL/regex.
  Токенайзер разбирает строки посимвольно (кавычки, экранирование `\'`, `\\`,
  `\r\n`, запятые и скобки внутри body), поэтому наивный split не применялся.
- Выделены только таблицы `articlex`, `articles`, `articles_column`, `cal`,
  `dic`, `dic_data`. Все шесть лежат в первых 3385 строках дампа (порядок
  определения a/c/d), читается только этот префикс - 16 ГБ целиком не грузились.
- **Кодировка (важно, расходится с ожиданием задачи).** DDL таблиц объявляет
  `DEFAULT CHARSET=cp1251` (хранение в БД - cp1251, как и пишет `legacy-map.md`),
  НО сам файл дампа снят с `SET NAMES UTF8`, поэтому **байты дампа - UTF-8**, а не
  windows-1251. Чтение `.sql` как cp1251 даёт мозаику (`РџСЂРёС‚С‡Р°` вместо
  `Притча`). Проверено на образце: cp1251-декод - мусор, utf-8-декод - чистый
  русский. Для финального конвейера: этот дамп парсить как UTF-8; при снятии
  свежего дампа зафиксировать `--default-character-set` осознанно.

## 1. Grid-композиция (гейтит ADR по grid)

Метод: среди корпуса `grid_tp != 0`; для каждого - какие `grid_art_{left,right,top,bottom}`
непусты (доноры), тип и `is_close` доноров.

Числа:
- Корпусных строк с `grid_tp != 0`: **2** (и во всей таблице articlex тоже только 2).
  - `id=1003` type=17 (Добротолюбие) url=`beganie-mira-...` -> встроен слева `id=1230`.
  - `id=1626` type=26 (Молитва) url=`molitva` -> встроен слева `id=1627`.
- Доноры: `id=1230` и `id=1627` - **оба type=19 (Фрагменты страниц = служебные)**,
  `is_close=0`, `url=''`.

Интерпретация: механика "статья встраивает другую статью в grid" в мигрируемом
корпусе фактически мертва - 2 случая из 1523. Оба донора не корпусные статьи, а
служебные "фрагменты" без собственного URL. Зависимость статья->статья как таковая
не живёт: это инлайновые вставки контента, а не связи между публикациями. Все равно 
подсистему grid в новую модель тащим;

## 2. Дубли слагов (вход ADR по слагам/URL)

|---|---|---|---|
| `zhitiya-svyatih` | 1154 | 1153 | 1153 корпус (Житие) + 1 оглавл |
| `pritcha` | 5 | 5 | корпус |
| `imenini` | 4 | 1 | 1 корпус + 3 оглавл |
| `feofan` | 3 | 3 | корпус |
| `siluan` | 2 | 2 | корпус |

| `ikona-na-imenini` | 2 | 0 | служебные |

Интерпретация: slug НЕ уникален и не задумывался уникальным. 1153 жития делят один
общий slug `zhitiya-svyatih` (это slug куста/раздела, а не статьи; согласуется с

генерировать уникальные слаги из title/id; (в) 6 корпусных коллизий кроме житий -
мелкий хвост, решаемый генерацией.

## Следствия

**Для ADR по grid-композиции (п.1).** Межстатейный grid в корпусе мёртв: 2 случая
из 1523, оба донора - служебные "фрагменты", а не статьи. Механику grid
(`grid_tp`, `grid_art_*`) в новую модель все равно несем - это решение. 
Зависимость статья->статья при миграции отсутствует - каждую
статью можно рендерить изолированно.

**Для ADR по слагам/URL (п.2-4).** `url` не уникален и не является идентификатором:
1153 жития под одним slug `zhitiya-svyatih`, плюс 8 мелких коллизий, плюс 2
корпусные статьи вовсе без slug. Канонический идентификатор - `id` (форма
`-lib<id>`). Решение по URL обязано включать id (либо гарантированно-уникальный
генерируемый slug + id-fallback). Внутренние ссылки на статьи (`-lib<id>`) битых
не содержат - карта id->новый URL строится однозначно.

**Для конвейера (п.4-7).**
- Перезапись body: 396 внутренних ссылок на статьи + 628 на оглавления/лендинги
  (нужны страницы-цели: 5 именинных nav + 3 житийных оглавления), 355 `/buy/` и 95
  внешних - отдельной политикой. Старой query-формы (`?article=`, `article.php`) в
  body корпуса нет.
- Медиа: ~355 редакционных JPG (`/images/`, `/htm/`); `/buy/`-превью (414) уходят с
  магазином; youtube не используется.
- Мета: title <- `pg_ttl` (100%), description <- `pg_dsc` (96.5%, добить генерацией
  на ~3.5%), `anons` пуст - не источник. На входе декодировать HTML-сущности в
  заголовках.
- Старый журнал (articles): отдельная подсистема, 39 htm-выпусков на диске, 12
  рубрик; кодировка htm - cp1251 (в отличие от UTF-8 байтов этого дампа).
