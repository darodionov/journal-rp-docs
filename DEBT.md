# DEBT.md — техдолг и напоминания

> **Протокол (для людей и для Claude).**
> Одна строка = одна запись. Формат: `- [ ] ГГГГ-ММ-ДД #тег текст`
> Тег — шаг плана (`#A11`, `#B2`), либо `#tooling`, `#docs`, `#design`, `#напоминание`.
> Сделано → меняем `[ ]` на `[x]`, строку не удаляем (история решений).
> Новое дописываем **в конец** соответствующего раздела.
>
> **Команды в чате:**
> — «запиши на память …» / «запиши напоминание …» → Claude формулирует готовую
>   строку в этом формате; вставляет владелец или Claude Code.
> — «что в долгах?» / «покажи долги по A11» → Claude ищет этот файл в знаниях
>   проекта и выдаёт актуальный список (при необходимости с фильтром по тегу).
>
> **Важно:** файл должен лежать в репозитории **и** быть добавлен в knowledge
> этого Project — иначе чаты его не увидят. После правок — пересинхронизировать
> проект, иначе Claude читает устаревший снимок.

Там, где раскладка обязана переносить элементы, число дорожек должен считать браузер — `repeat(auto-fit, minmax(минимум, 1fr))`, — и тогда минимум дорожки становится осмысленной величиной «карточка не бывает уже этого», а не нулём. Ноль в `minmax(0, 1fr)` лечит переполнение длинным словом, но той же строкой разрешает сетке давить содержимое до исчезновения: роли разные, запись одна, и путать их нельзя
