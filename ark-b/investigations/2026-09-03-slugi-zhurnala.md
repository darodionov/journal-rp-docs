**Правила сжатия, читаемые в образцах (мой рабочий стандарт для шага 2):**

1. **Снимаются титулы/саны и служебная обвязка:** «Святитель / Преподобный / Свт. / Св. / Преп. / Блаженный / Схимонах / Старец / Мученик / Князь / о.», а также хвосты «Память…», «Житие, молитва, канон», «Беседа/Разъясняет NN». Остаётся ядро *имя + различитель*.
2. **Порядок — имя, потом эпитет/место:** `ignatii-bryanchaninov`, `feofan-zatvornik`, `adrian-ondrusovskii`. Заголовок с саном впереди («Молчальникъ Михаилъ») разворачивается в имя-первым.
3. **Инициалы и отчества выбрасываются** (в корпусе `sergei-aleksandrovich-nilus` — исключение с сохранением; массово — нет).
4. **-ий/-ый/-ой/-ей → -ii/-yi/-oi/-ei:** `serbskii`, `svetonosnyi`, `velikoi`, `andrei`. Дореформенные буквы приводятся к современным **до** транслита (ѣ→е, і→и, ѳ→ф, ѵ→и), конечный `ъ` отброшен: `Св&#1123;тоносный→svetonosnyi`, `Лѵра→lira`.
5. **Числа/римские цифры/годы сохраняются как различитель тёзок:** `ilarion-novyi-845`, `aleksandr-iii`. Для дублей-заголовков — суффикс `-<id>`: `serafim-sarovskii-73`.
6. **Тематические статьи (без лица) сворачиваются к теме/вопросу:** `usynovlenie`, `angelah-arhangelah`, `rabotat-akterom-greh-li`; вопрос-титул сохраняет вопросительную формулу, автор в слаг не идёт.
7. **Длина:** медиана 16, обычно 1–2 слова; практический потолок ~45 (в таблице всего 5 строк длиннее, максимум 51). Транслит-схема корпуса: `х→h, ц→c, ч→ch, ш→sh, щ→sh, ж→zh, ю→yu, я→ya, ы→y, й→i, э/е→e, ъ/ь→∅`.

## ШАГ 2. Нормализация входа и предложенные слаги

**Конвейер нормализации каждого заголовка (до транслита):**
1. Латинские двойники → кириллица: `i→і, I→І, C→С, A→А, o→о` (Адрiанъ, Cергей, Ioной, Кiевскимъ, Aверкiй).
2. Сущности: `&#1141;→ѵ`, `&#1123;→ѣ`.
3. Дореформа → современная: `ѣ→е, і→и, ѳ→ф, ѵ→и`, конечный `ъ`→∅.
4. Снять сан/титул/инициалы, оставить *имя + различитель*, порядок «имя-эпитет».
5. Транслит по схеме корпуса; числа/части сохранить.

40 слагов сведены в таблицу шага 4. Ключевое по нормализации: `Адрiанъ→Адриан`, `Кiевскимъ→Киевским`, `Aверкiй→Аверкий`, `Собратiя→Собрания` (Собратия), `Посещения→posesheniya` (щ→sh), `Иисусова→iisusova`, `Царю→caryu`.

### ⚠️ Развилка, которую не решаю молча (по методу CLAUDE.md)

Эти 40 — **выпуски старого журнала** (`articles.num = 0…39` из дампа; №0 — история → `/journal`), это **другое пространство id**, чем корпусные `pages`. В `slug-table.tsv` id `3…39` **уже заняты** корпусом (напр. id11 = `venok-imperatora`), поэтому вставить эти строки туда с ключами `0…39` нельзя — `identify.ts` сломается. По `redirects-manual.tsv` их естественный дом — колонка `target` строк `family=issue, key=article=N` (там пусто, помечено «цель при проектировании /arhiv (B2)»).

**Слаги при этом валидны и проверены против всего URL-namespace** (коллизий нет) — генерация корректна независимо от места. Открыт только **ключ/файл-назначение**: (а) `target` в `redirects-manual.tsv`; (б) отдельная таблица выпусков; (в) `slug-table.tsv` со смещённым id (тогда нужен твой оффсет). Ниже блок даю с ключом `article=N` — это честный легаси-ключ выпуска, он визуально не int, чтобы случайно не попал в `slug-table.tsv` как есть.
