## 3.2. Материал к alt-политике (вопрос В2)

состояние `alt` (непустой / пустой / нет атрибута) и `title`. Кандидат
подписи — ближайший непустой текст 3–120 символов: соседи после и до
картинки (пропуская `br`/`img`), затем соседний узел родителя, затем
собственный текст родителя.

## 3.3. Метаданные N=0 (история журнала)

**Страница.** `0/!.ogl`: легенда «Русскiй Паломниъ» (опечатка — потеряна
«к»), © издательства, h1 «ИСТОРИЯ ЖУРНАЛА», лид дореформенным набором
(ять через `&#1123;`), оглавление из 4 глав
`jurnal.php?name=history&num=0&page=0..3`. Номера-года нет (у выпусков в
`!.ogl` стоит «№18-1998 г.» и подобное).

`0/index.htm` (5387 байт, современная орфография): h1 «Православный Журнал
Русский Паломник», «120 ЛЕТ … 1885 – 2005», четыре секции h3; источник
назван в теле — газета «Леушино» №5/106, 05.03.2005; картинки image001–005
несут и `alt`, и `title`. Файлы `image006.jpg`/`image007.jpg` на диске —
сироты (в теле не упомянуты). Глав 3–4 оглавления («Плачь Серафима Роуза о
Россiи», «Совесть Русского Зарубежья») файлов не существует — в папке лишь
`index.htm`; `history.php` живого сайта читает именно его
(`ReadHTMLFilesXX(0)`), значит и легаси показывал только этот состав.

**Механика адреса.** `.htaccess:254`:
`RewriteRule ^journal /pages/article/history.php?rd=1 [L]`; строки 255–256:
прямой заход на `/pages/article/history.php` → 301 на `/journal`.
`history.php` задаёт заголовок и описание жёстко в коде: `pg_ttl`
«Православный журнал Русский Паломник», `pg_dsc` «История возрождения
православного журнала Русский Паломник».

**БД.** SSH-туннель конвейера из сессии недоступен (ключ читается только
пользователем `dr`), поэтому вместо живой базы — один проход по дампу 2018
(16,7 ГБ): 126 таблиц; `pg_main` таблицей не является (это PHP-класс
`bean/pg_main.php`). Строк `history.php`, `jurnal.php`, `name=history` во
всём дампе — **0**. `/journal` — 35 вхождений, весь след шумовой:
`partner_jumps` (19) — рефереры `my.mail.ru/community/*/journal`; `logx`
(14) — CSP-отчёты со страницы товара `/buy/journal-russkii-palomnik-t568/`;
`products_tag` (2) — HTML тега того же товара. Числового id у страницы
истории нет нигде: таблица `articles` несёт строго `num` 1..39
(`smallint unsigned`, AUTO_INCREMENT=40), записей для 0 и −10 нет.
Идентичность держится на четырёх опорах: папка `all/0`, константа 0 в
`history.php`, `num=0` в ссылках `!.ogl`, правило `.htaccess`.

**Предложение фронтматтера оверрайда** (решение примет владелец; ADR-0008-m
п. 10 фиксирует `legacyId` = 0, `source: "zhurnal"`, рубрику
`russkiy_palomnik`):

```yaml
title: Православный журнал «Русский Паломник»   # h1 тела = pg_ttl history.php
description: История возрождения православного журнала Русский Паломник
cover:
  src: /pages/article/all/0/image002.jpg         # первая редакционная по порядку (0005-m)
  alt: Дореволюционный вид журнала Русский Паломник
slug: istoriya-zhurnala                           # предложение; финал через slug-table.tsv
datePublished: 2005-03-05                         # дата источника (газета «Леушино»)
dateCreated: 2005-03-05
rubrika: russkiy_palomnik                         # раздел /journal/, рубрика o-zhurnale
legacyId: 0
# source: zhurnal, magazine-полей не несёт (не выпуск)
```

дат — правило нулевых дат 0004-m, но здесь дата известна из источника.
