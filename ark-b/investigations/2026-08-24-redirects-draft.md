**Расхождение с ожиданием 628 — поимённо, без подгонки.** Ожидание
(628 = 5 житийных + 623 именинных на 5 nav) посчитано против корпуса ДО вывода
именинного куста. Проверка по полной таблице:

## 5. Самопроверка (перед сдачей)

| Проверка | Результат |
|---|---|
| сумма вх. по 8 оглавлениям = найденным целям вне корпуса | 5 = 5 ✔ (ожидание 628 — не совпадает, объяснено в п.2) |
| issue: `article=*` = записей articles | 39 = 39 ✔ |
| issue: `column=*` = записей articles_column | 12 = 12 ✔ |
| у каждой строки заполнены family, key, legacy_url, source | 0 пустых ✔ |
| target пуст ⇔ status начинается с forward | 0 нарушений ✔ (все цели пусты — ничего ещё не перенесено) |

Черновик: **64 строки** данных (issue 51 = 39 выпусков + 12 рубрик; point 5;
toc 8). Сортировка family→key (issue: `article=` по N, затем `column=` по M).

**Расхождение со счётом владельца (65) — 1 строка, показываю, не подгоняю.**
Ожидание «issue 51, всего 65» = 53 (прежний черновик) + 12 рубрик. В нём не
вычтен ряд `/article.php?id=`, удаляемый по тому же пакету решений (п.4): он был
в прежнем черновике point-строкой (с пометкой ВОПРОС), теперь убран → point стал
5, а не 6. Поэтому фактический итог 64. Чтобы вышло 65, надо было бы оставить
`/article.php?id=` в карте, что противоречит п.4. Оставлено 64; при построчном
ревью подтвердить.

**Закрыты решениями 2026-08-24** (были вопросы 1, 3, 4, 5 первой редакции):

**Остались в силе** (из прежних пяти — Q2, Q6, Q7, Q8, Q9):

- **[СНЯТ] Q2 — арка/статус старого журнала.** Разрешён п.2: кластер старого
  журнала (39 выпусков + 12 рубрик + `/journal` + `/article/`) остаётся
  forward-b2, цели решаются при проектировании `/arhiv` в B2. Отдельный статус
  не вводится (п.1: карта одна, по аркам не делим). Действий не требует.

- **[В СИЛЕ] Q6 — 4 оглавления вне восьмёрки.** type7: 1322

  семейством/статусом) или оставить мосту/410?

  папки `40`/`41` отсутствуют (реально `-10, 0..39`), «43 папки / N=-10..41» —

- **[В СИЛЕ] Q9 — `/htm/fair/expo.htm` → `/afisha`** (.htaccess:90). Отнёс к

**Итог: в силе три содержательных вопроса — Q6, Q7, Q9.** Q2 снят решением п.2,

входит. (Строку в DEBT-B не добавлял — вне двух файлов задачи; по команде внесу.)
