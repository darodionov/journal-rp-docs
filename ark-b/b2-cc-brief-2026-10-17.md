# Задание Claude Code — остаток шага B2 вне кода страниц (2026-10-17)

Арка B, шаг B2 (индекс метаданных и разделы лент). Декомпозиция —
`journal-docs/ark-b/b2-decomposition.md` ред. №4; ADR-0008-m с эрратой
2026-09-14; долги — `journal-docs/DEBT-B.md`. Передача прошлого чата —
`journal-docs/ark-b/b2-handoff.md` (ред. 2026-09-14): задание из её раздела
«Для Claude Code» выполнено и закоммичено целиком.

## Разделение труда с этого дня

Владелец пишет код страниц сам, в чате с наставником: лента рубрики (P6),
главная на индекс (P7), затем хабы. Туда же отнесена страница статьи в части
строки даты и JSON-LD — она делит предикат и хелпер подписи с карточкой ленты.
Этот документ — всё остальное. Правила прежние: один сеанс на рабочее дерево
(DEBT-B 2026-09-04); коммит — только по явному подтверждению владельца,
сообщение коммита предложить, не сочинять молча; `npx tsc --noEmit`,
`npx eslint src`, `npx vitest run` чистые перед каждым предложением коммита.

Зависимости обозначены у каждого пункта: «без зависимостей» — можно сразу;
«после предиката» — ждёт коммита ветки 1 с `isMigrated` и `vypuskLabel`;
«решение владельца» — пункт не начинается, пока владелец не ответил. Claude
Code решений за владельца не принимает.

## Решения на входе

1. **P5.6 — вариант Б с подвариантом Б1** (прочтение наставника 2026-10-17
   по ответам владельца; владелец подтверждает первым сообщением ветки 1).
   Формулировка: «Мигрированная статья (признак `legacyId !== undefined`;
   ноль у истории журнала — мигрированная) даты публикации не заявляет: на
   карточке ленты и на странице статьи строки даты нет, у статей
   `russkiy_palomnik` вместо неё — подпись выпуска из `magazineNum` и
   `magazineYear` по наличию; JSON-LD страницы у мигрированных без
   `datePublished` и `dateModified`; RSS мигрированные не включает; sitemap
   отдаёт `lastmod = datePublished` у всех, потому что это дата изменения
   адреса, а не публикации текста. Предикат живёт в одном доме рядом с
   `isRusskiyPalomnik` и вызывается со всех поверхностей.» Проверка
   истинностью (`if (meta.legacyId)`) запрещена: ноль — ложное значение, а
   у истории журнала `legacyId` равен нулю по ADR-0008-m п. 12.
2. **RSS отложен** решением владельца 2026-10-17; маршрута нет. Правило для
   будущей реализации записывается строкой долга (пакет 1, п. 4).
3. **Страница статьи получает строку даты**, которой в макете
   `Statiya_3_1980-1` нет, — решение владельца 2026-10-17; место и стиль за
   владельцем, содержимое по P5.6. Реализует ветка 1; здесь — только строка
   долга (пакет 1, п. 4).
4. **Открытые вопросы владельцу** (из передачи, остались 2–5): вход в четыре
   малых раздела (P8; рекомендация — дровер как основной вход, футер как
   дублирующий); 18 статей журнала без координат и история, недостижимые
   изнутри сайта (три пути из эрраты ADR-0008-m); есть ли макет хаба
   журнала; группировка номеров по годам на хабе. Первый нужен пакету 1,
   п. 2; второй — пакету 2, п. 6; третий и четвёртый — ветке 1.

## Пакет 1 — без зависимостей

   приёмок P2 и P3 декомпозиции): unit-тесты шести списковых методов порта
   на подвыборке; негативная типовая проверка через `@ts-expect-error`
   (несуществующее значение аргумента не компилируется); контракт-тест
   слеша на всех новых хелперах `src/lib/routes/` (ни один путь, кроме
   корня, не оканчивается слешем); снапшот пятнадцати адресов готовыми
   строками (одиннадцать подрубрик, четыре источника); сторож резерва —
   слаг `page` или `nomer` в любой таблице рубрик роняет тест; границы
   `paginate` (страница 0, последняя, последняя + 1, пустой список),
   `pageFromSegment` (`02`, `1e1`, `1`, `0`, пусто) и `monthFromSlug`
   (неизвестный слаг, регистр). Дымовой скрипт `scripts/smoke/not_commit/…`
   — образец ожиданий, в коммит не идёт. После: закрыть соответствующие
   строки DEBT-B по свидетельству (имена файлов, число тестов).
2. **P8 — шапка и дровер, стадия 3** политики ссылок chrome (мини-ADR A10).
   «Журнал» → `razdelPath('russkiy_palomnik')`, «Жития Святых» →
   `razdelPath('zhitie')`; адреса только через хелперы `src/lib/routes/`,
   никакой склейки строк (ADR-0009 п. 1). Дровер перечисляет реальные
   рубрики через хелперы и подписи `labels.ts`; в мигрированных пунктах не
   остаётся `href="#"`; внутренние ссылки — `next/link`. `aria-current` в
   шапке сейчас стоит жёстко на «Журнал» (паспорт as-built, открытый
   пункт 5) — сделать активной ссылкой по текущему маршруту без превращения
   шапки в клиентский компонент сверх необходимого: если нужен
   `usePathname`, остров — только сам список ссылок, не вся шапка. Вход в

3. **Гигиена кода, найденная при чтении вложений 2026-10-17** (мелкое, одним

## Пакет 2 — после предиката из ветки 1

5. **Sitemap (P9)**: `src/app/sitemap.ts` получает хабы шести разделов,
   рубрики, номера и страницы пагинации — через порт и хелперы
   `src/lib/routes/`, не склейкой. Адресов `…/page/1` в sitemap нет
   (страница 1 живёт на базовом адресе). `lastmod` статей — `datePublished`
   у всех, без ветвления по `isMigrated` (подвариант Б1); у списковых
   адресов `lastmod` не ставить — выдуманная дата хуже отсутствующей.
   Приёмка: `/sitemap.xml` после `npx next build && npx next start`
   перечисляет разделы; число адресов статей равно размеру индекса (60);
   тест или дымовой скрипт на отсутствие `/page/1` и завершающих слешей.
6. **Редиректы (P9)**: в `data/redirects-manual.tsv` строки со статусом
   `forward-b2` получают цели (семейство `issue`: `article=<N>` → адрес
   статьи журнала по слагу из таблицы B1б, `column=<M>` →
   `/journal/<podrubrika>` по таблице ADR-0008-m п. 5, `column=10` → хаб
   `/journal`; житийные оглавления lib26/63/64 и lib1322 →
   `/zhitiya/<istochnik>`, соответствие проверить по исследованию;
   месячные lib1325–1336 → `/zhitiya/<mesyac>`; `history.php` →
   `/articles/istoriya-zhurnala`). Цели строятся хелперами, не руками.
   Перепрогон `map_redirects.ts`: md5 стабилен между прогонами, учёт
   «разрешено + ждут цели = прочитано» сходится с новой арифметикой
   (`EXPECTED_MANUAL_REDIRECTS` = 69 не меняется). Тест: каждая цель со
   статусом `forward-b2` принадлежит множеству адресов B2, построенному
   хелперами (таблица ADR-0008-m п. 9). Судьба 18 статей журнала без
   координат — **решение владельца** (открытый вопрос 4), до него
   соответствующие цели не выставлять.
7. **Сверка DEBT-B**: каждая строка, адресованная B2, имеет вердикт
   (закрыта со свидетельством или перенесена с указанием шага). Список
   строк без вердикта — владельцу.
