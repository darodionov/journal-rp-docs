# Декомпозиция B1б: миграция старого журнала (39 выпусков + история)

- Статус: согласована владельцем 2026-09-03 («черновик ок»); вопросы
  В1–В4 закрыты решениями 2026-09-03 — внесены по тексту и в раздел внизу
- Канон решений: ADR-0008-m (в черновике значился как 0006-m);
  эррата 2026-09-02 к ADR-0009; спецификация
  `design/b1-pipeline-spec.md` §1–2 (болячки Б1–Б11)
- Свидетельства: `ark-b/investigations/2026-09-02-b1b-issledovanie.md`
- Образец формы: `ark-b/b1-decomposition.md`

## Конструктивные решения (защиты — по образцу B1)

1. **Новая голова, старый хвост.** B1б добавляет стадии-добытчики, кладущие
   39 записей `source: "zhurnal"` в общий `corpus.jsonl`; хвост конвейера
   (convert → copy_img → rewrite_links → compose_fm → write_mdx →
   map_redirects → report) прогоняется по объединённому корпусу 1338 + 39.
   Защита: один код конверсии и перезаписи на оба источника; расхождение
   двух хвостов — класс багов, который не лечится, а только заводится.
2. **Подвыборки нет.** 39 выпусков — весь вход ветки; контрольное число 39
   (несходство = смерть). Дисциплина B1 целиком: dry-run, отчёт,
   идемпотентность, манифест перепрогона, оверрайды.
3. **Слаги приходят таблицей, генератор не пишется.** Прожитое решение
   2026-08-22/24: LLM-генерация недетерминирована и не может быть стадией
   конвейера — слаги порождаются разово через CC, ревьюются глазами,
   коммитятся в `data/slug-table.tsv`, входят в S3 приоритетом над
   алгоритмом (приёмка S3 2026-08-27: `table: 1338`, ступени 3–4 не
   написаны сознательно). B1б повторяет процедуру для 40 журнальных
   записей. Защита: перенос разовый — постоянный механизм ради разовой
   задачи не строится; детерминированность обеспечена тем, что в репо
   лежит застывший результат, а не вызов модели.
4. **Легаси и дамп — только чтение.** Правка `title` (гомоглифы) происходит
   при ингесте в `corpus.jsonl`, источник не трогается.

## Гейты (до кода)

- ADR-0008-m принят, бывшие ⚠ закрыты (2026-09-03): схема выпуска —
  вариант union `rubrika: 'vypusk'` с обязательными `magazineNum`,
  `magazineYear`, `zhurnalRubrika`; суффикс — две ступени (`-<legacyId>`,
  остаточная коллизия → `-vypusk-<num>` у журнальной записи);
  `legacyId` истории = 0, неотрицательность для `zhurnal`.
- Схема A4 обновлена под решение выше; уникальность `corpus.jsonl` — по
  паре `(source, legacyId)`; существующие сторожа корпуса переучены на пару.
- `EXPECTED_CORPUS_COUNT` осознанно меняется: 1338 → 1378 (+39 выпусков,
  +1 история журнала, В4 2026-09-03).

## Подзадачи

**J1. Обход и декод.** Вход: `pages/article/all/`. Делает: обходит строго
папки `1..39` (исключения по Б11: `0` — отдельная судьба J8, `-10`, `av/`,
`template.htm`); каждый `*.htm` и `!.ogl` декодируется cp1251 → UTF-8
строго без -c (непреобразуемый байт = ошибка файла в отчёт). Выход:
39 сырых записей (тело-фрагмент, сырой `!.ogl`, список файлов папки)
во внутреннем артефакте стадии. Отказ: папок не 39 — смерть; байт не
декодируется — ошибка записи, прогон жив, exit code ненулевой.

**J2. Слияние метаданных (Б3, Б5, Б10).** Вход: J1 + таблица `articles`
(39 строк) + справочник `articles_column` + `<META>` тел четырёх выпусков
(26, 35, 38, 39 — у них нет `!.ogl`). Делает: эвристический парсер `!.ogl`
(роли h1/h2/h3 плавают — №1, №17, №30 поимённо в спецификации); правило
приоритета: БД — машинные поля (`title` современного написания, `column`,
`date`), `!.ogl` — номер-год (`magazineYear`), дореформенный заголовок —
в тело как H1, КАПС не тащить в meta; сверка `magazine_num` БД ↔ номер из
`!.ogl`; оверрайды на выпуск — механизм конвейера, файл версионируется.
Выход: 39 полных метазаписей + построчный отчёт извлечений для ручной
сверки. Отказ: конфликт без правила и без оверрайда — карантин выпуска
с самодостаточной причиной, не смерть.

**J3. Нормализация заголовков.** Вход: J2. Делает: латинские гомоглифы →
кириллические кодепойнты (i→і, I→І, C→С, A→А, o→о; ADR-0008-m п. 8),
декод entities; правится `title` ингеста, дореформенность сохраняется.
Выход: чистые заголовки. Отказ: незнакомый не-ASCII символ вне таблиц —
карантин, в отчёт (таблица пополняется осознанно, не молча).

**J4. Ингест в corpus.jsonl.** Вход: J1–J3. Делает: 39 записей
`source: "zhurnal"` в общий `corpus.jsonl` тем же форматом полей (+ поля
выпуска по решению гейта); стабильный порядок; идемпотентность —
перепрогон даёт байт-в-байт тот же файл. Выход: corpus 1377 (1378 после
J8), сторожа пары обновлены. Отказ: коллизия пары — смерть; несходство
контрольных чисел (1338 старых нетронуты, 39 новых) — смерть.

**J5. Слаги журнала — пополнение таблицы (не код).** Вход: 39 заголовков
+ история, схема `data/slug-table.tsv` (четыре колонки), образцы
конвенции коротких слагов из существующих 1342 строк. Делает: разовая
генерация через CC по промпту с образцами; ревью владельца глазами;
проверка на коллизии с существующими 1342 и между собой; дописывание в
таблицу и коммит. Кода генерации не появляется — ступени 3–4 S3 остаются
ненаписанными сознательно (решение 2026-08-22/24). Выход: таблица
покрывает 1378 записей корпуса; двусторонняя стыковка S3 сходится.
Отказ: коллизия или запись без слага — правится в таблице руками до
прогона, не эвристикой в коде.

**J6. Тела выпусков (Б2, Б4, Б7, Б8).** Вход: J1, J4, S4-хвост. Делает:
толерантный парсер HTML-фрагментов; `<META>` четырёх выпусков выдрать во
фронтматтер, из тел убрать; entities → юникод (20459 вхождений), орфографию
не модернизировать; нормализация гомоглифов тел по отчёту 3.1 от
2026-09-03 (4500 вхождений, 97 % — i): карта заголовков применяется к
кириллическим словам с вкраплениями; римские числа смешанного набора
(IХ, ХIV, ІV) не трогать; буквы без кириллического двойника — в отчёт,
не в конвертацию; счётчики до/после — в отчёт; №30 — склейка шести глав
`makaria*.htm` в один MDX с якорями, оглавление `!.ogl` → якоря,
мусорный `</html>` толерантно; межвыпусковые `article.php?article=N` →
через генерируемую карту (как `-lib` у articlex); магазинные — по прожитой
политике без изменений (В3): приравнены к `/buy/` (эррата 2026-08-24),
переписываются на абсолютные `https://idrp.ru/…`, как S7 уже делает для
корпуса; счётчик в отчёт. Выход: 39 MDX-тел через общий хвост.
Отказ: незнакомый тег — карантин выпуска, прогон жив.

**J7. Картинки (Б6).** Вход: папки выпусков, ADR-0010, 0005-m. Делает:
перенос по конвенции контент-дерева; размеры — из атрибутов, иначе
измерять файл; alt (В2): существующие 14 сохраняются; остальным — пустой
`alt=""` (у 200 из 218 рядом видимая дореформенная подпись — пустой alt
при видимой подписи корректен), кандидаты подписей из отчёта 3.2 — в отчёт
конвейера как материал редакционной работы, конвейер их не присваивает;
`art.jpg` (есть у всех 39, в теле не упоминается) → `cover`;
неиспользуемые файлы семи папок не переносить, поимённо в отчёт.
Выход: медиа в `public/`, отчёт. Отказ: битый файл при назначенном
cover — карантин (по 0005-m).

**J8. История журнала (N=0).** Вход: оверрайд с фронтматтером по
исследованию 3.3 (фронтматтер утверждает владелец), `legacyId` = 0. Делает:
миграция как обычной статьи, `source: "zhurnal"`, рубрика `o-zhurnale`;
редирект `history.php` → её адрес (рукотворная карта). Выход: сороковая
журнальная запись. Отказ: пустой оверрайд — карантин, не выдумывание.

**J9. Карты и ревизия рукотворной.** Вход: S10 + эррата п. 4. Делает:
генерируемая карта пополняется формой `article=<N>` из журнальных записей;
рукотворная перегоняется: 39 issue-строк уходят, цели `column=<M>` и
житийных заполнены, `/journal`-строка удалена, `history.php` добавлена;
самопроверки числа строк. Выход: обе карты, отчёт разрешения адресов.
Отказ: цель вне множества хелперов маршрутов — смерть.

**J10. Полный перепрогон и отчёт.** Хвост S4–S11 по корпусу 1378;
манифест-чистка сирот; второй прогон — md5 совпали; отчёт: счётчики по
рубрикам журнала, entities, гомоглифы тел, ссылки, картинки, оверрайды,
конфликты источников, карантин поимённо.

## Приёмка («Готово»)

1. 39 выпусков + история открываются в браузере по `/articles/<slug>`;
   дореформенный текст читаем (Ѣ Ѳ Ѵ рендерятся PT Sans, не тофу);
   №30 — главы под якорями, оглавление кликабельно.
2. `corpus.jsonl`: 1378 записей, уникальность по паре, 1338 старых
   байт-в-байт нетронуты.
3. Слаги: все 1378 уникальны; таблица покрывает корпус целиком
   (origin table для всех записей, как на приёмке S3 2026-08-27); отчёт
   называет, сколько слагов журнала потребовали суффикса.
4. Карты: `article=<N>` разрешается генерируемой картой; рукотворная
   соответствует эррате построчно; десяток реальных легаси-адресов
   (подберёт владелец) проходят макет разрешения.
5. Идемпотентность: md5 второго прогона; намеренные поломки (владелец):
   порча байта cp1251 → ошибка файла; дубль пары → смерть; выпуск без
   `!.ogl` вне четвёрки → карантин.
6. Отчёт достаточен для назначения редакционной работы без открытия базы.

## Закрытые вопросы (решения 2026-09-03)

- **В1** — по поручению владельца, наставником (ADR-0008-m пп. 3, 4, 10):
  схема выпуска — вариант union `vypusk`; суффикс — двухступенчатое
  правило; `legacyId` истории = 0.
- **В2** — владелец: пустой alt + отчёт; существующие 14 alt сохраняются;
  200 кандидатов подписей (отчёт 3.2) — редакционный материал, конвейером
  не присваиваются.
- **В3** — владелец: прожитая политика S7 без изменений — приравнены к
  `/buy/`, абсолютизация на `https://idrp.ru/…`.
- **В4** — владелец: история входит в счёт, `EXPECTED_CORPUS_COUNT` = 1378.

## Не входит (сознательно)

Вёрстка раздела `/journal/` и всех лент (B2); работающие редиректы (B4);
универсальная пагинация длинных статей (DEBT-B 2026-09-02); слаги
немигрированной части корпуса на B5 — той же процедурой таблицы, объём
считает отдельное исследование; алгоритмический генератор не пишется
ни здесь, ни там (решение 2026-08-22/24, ADR-0008-m п. 8).
